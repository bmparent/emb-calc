# Production companion design contract

Source: mobile-workflow.png, generated 2026-09-07 for the approved A–B–C flow.

True white canvas; navy #172033 text; muted #52617b; indigo #4f46e5 primary; pale gray #f3f5f9 panels. System type: 16px body/input, 14px helpful text, 26–30px page headings, 44px duration. Minimum 44px controls. 24px outer desktop gutters / 20px phone gutters. 12px panel/button corners. Bottom navigation Jobs, New estimate, Tools, Shop. One primary action per workflow step.

A: What are we making? Garment choices, quantity, machine, manual stitches or DST, placement, optional advanced details. B: Your production plan, total/machine/labor minutes, batch plan, time breakdown, editable costs, quote total. C: Ready when you are, named saved job, share quote, explicit start/paused/completed states. Supporting views: job cards, local color tools, shop profile editor and backups use the same tokens.

Intentional differences from illustrative concept: live computed amounts replace all invented mock values; native status bar is provided by iOS, not drawn inside the website; display no fake phone frame. Manual entry is always directly available (no redundant mode button). Multiple placements, warning retention, recovery controls, and job lifecycle details are required functional additions. A real DST SVG preview comes from decoded points; no raster is used for charts or controls. The previous marketing wrapper is removed on /calculator/ but remains on editorial pages.
